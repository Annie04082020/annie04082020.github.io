# KV260 + RaspicamV2 Realtime Filter

Authour: Annie, Chao
Reference: [ultra96v2_imx219_to_displayport](https://github.com/gtaylormb/ultra96v2_imx219_to_displayport)

## Input Method
- Enter number/code in terminal
- Communicate with PC through UART 
(Since there's no switches and buttons for KV260...)

## Filters

- Original
- Binarization (Threshold)
- Colour Reversion
- Gamma Correction
- Colour Extraction
- Edge Detection (Sobel)
- Pencil Sketch [Sketch Effect](https://github.com/Annie04082020/FPGA_Final_prj)
- Colour Extract + Edge Detect(only find the edge on specific colour)

## Modification Method

Mostly the filters can be done by modifying the .c/.h files in Vitis(Software), but some of them might need new IP.

## UART Encode/Decode

1 bit mode selector
0: Original
1: Binarization
2: Colour Reversion
3: Gamma Correction
4: Colour Extraction
5: Edge Detection
6: Pencil Sketch
7: Colour Extract + Edge Detect
