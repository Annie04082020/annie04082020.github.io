## Displaying RaspiCamv2 from HDMI by kv260 board

## Steps:

1. Install Vivado and Vitis 2021.2 Version [AMD Unified Installer](https://www.amd.com/en/support/downloads/adaptive-socs-and-fpgas/development-tools/2021-2.html)

2. Clone the project : [ultra96v2_imx219_to_displayport](https://github.com/gtaylormb/ultra96v2_imx219_to_displayport)
```
git clone https://github.com/gtaylormb/ultra96v2_imx219_to_displayport.git
```

3. Open a new Vivado project

4. Type in commands in **tcl console**: 
```
set_property board_part xilinx.com:kv260_som:part0:1.2 [current_project]  
set_property board_connections {som240_1_connector xilinx.com:kv260_carrier:som240_1_connector:1.2} [current_project]  
set_property target_language Verilog [current_project]  
set_property default_lib work [current_project] 
```
  
#### source block design tcl（**Change the path to your folder**）  
```
source {C:/path/to/fpga/bd/imx219_to_kria_displayport_vivado2021.2.tcl}`
```
  
#### Save to Block Design
```
save_bd_design_as -dir build -force design_1.bd
```

5. Delete tpg ip and related ILA(It will take forever if you keep this), and reconnect the line 

6. Modify AXI SmartConnect Master Ports

7. Unassign and Assign all by Adress Map

8. Synthesis

To solve compiling problem: [Export IP Invalid Argument / Revision Number Overflow Issue (Y2K22)](https://docs.amd.com/r/en-US/76960/Export-IP-Invalid-Argument/Revision-Number-Overflow-Issue-Y2K22)

9. Implementation

10. Type Command in tcl console:
```
read_xdc {(Your path to fpga)/constraints/Kria_KV_CarrierCard_Rev1.xdc}  
opt_design
```
then Generate Bitstream

11. Export Hardware (.xsa)

12. Open a new vitis platform project using the .xsa

13. Right click and build the platform

14. Open a new vitis application project based on the platform

15. Choosing the blank C project, copy all ```software/src``` files except ```tpg.h``` and ```tpg.c```, comment out everything related to tpg

16. Right click and build the project

17. Debug Configurations --> Target Setup, **unselect the ```Use FSBL flow for initialization```**

18. Right click Run as --> Hardware
